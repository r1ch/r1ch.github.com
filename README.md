# bradi.sh

GitHub Pages site, served straight from `master` (no build step). Mostly old experiments; nothing here is deleted, only filed.

## Live

| Path | What |
|---|---|
| `/` (`index.html`) | Flowers: an endless field that spells "bradish". `/?hello` spells something else; `/?victorian` (or `/?victorian&hello`) paints it as a Victorian watercolour on vellum. Code: `js/flowers.js` |
| `/flowers` | Same page (kept so old links work) |
| `/tiles` | The previous homepage: drifting d3 tiles |
| `404.html` | Flowers again, grey, spelling "404" |
| `/g` | Link to the recipes site |
| `/wordle/` | Wordle helper (installable web app: don't move it) |
| `/faff/` | "Oh My Faff" and the lifts / piste-map prototypes (`lifts.html`, `lifts2.html`) |
| `.well-known/`, `CNAME`, `_config.yml` | Site plumbing |
